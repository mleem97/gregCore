## 2024-05-14 - [Centralize FishNet RPC Broadcasts]
**Learning:** Hardcoding commented-out missing method references leads to future compile errors when uncommenting code. Also, EventPayload objects in compatibility classes often require mapping values directly from strings that are dynamically structured in upstream patches.
**Action:** When stubbing unimplemented RPCs, construct the full structural definition using a placeholder bridge. When mapping event payload arguments (like 'serverId'), explicitly fetch and validate them using `TryGetValue` on the payload rather than implicitly relying on the method signature.
