[h1]gregCore — Framework for Data Center Mods[/h1]
[i]A foundational MelonLoader framework required by many gregMods.[/i]

[h2]What is gregCore?[/h2]
gregCore provides the shared infrastructure that powers mods like HexViewer, BetterQoL and others. It is not a gameplay mod by itself, but without it those mods will not load.

[h2]Features[/h2]
[list]
[*] Centralized UI Toolkit layer system (HUD, Panels, Dialogs, Overlays)
[*] Fluent panel builder API for in-game settings and mod menus
[*] Shared IL2CPP interop helpers and safety wrappers
[*] Theme & font management for consistent mod UIs
[*] Cross-mod communication and dependency resolution
[/list]

[h2]Requirements[/h2]
[list]
[*] [url=https://melonwiki.xyz]MelonLoader[/url] (0.7.x or newer)
[*] Data Center (latest Steam version recommended)
[/list]

[h2]Installation[/h2]
[list]
[*] Install MelonLoader for Data Center
[*] Subscribe to this Workshop item (or place gregCore.dll into your Mods folder)
[*] Restart the game — gregCore will load automatically before dependent mods
[/list]

[h2]For Mod Developers[/h2]
If you are building a mod on top of gregCore, add it as a MelonAdditionalDependencies and reference the gregCore.dll in your project.
